# Poppy's Love
A small Ren'Py visual novel featuring Poppy.

THIS GAME IS PERSONALIZED AND MEANT FOR A USER ON YUMESHIPPER APP.

## About

Poppy's Love is a personal visual novel project centered around spending time with Poppy, talking with her, and getting to know each other.

The game includes:

- Interactive conversations
- Affection system
- Multiple responses to "I love you"
- Player name input
- Player pronoun input
- Player birthday input
- Random idle conversations
- Time-based background changes
- Persistent game data
- First-install tracking
- Crash detection
- Multiple character expressions
- Custom UI
- Main menu
- Save/load system
- Dialogue history
- Skip and auto modes

## Background Cycle

The game changes its background based on time spent playing:

- Noon
- Day
- Evening
- Night

After four hours, the cycle starts again at Noon.
